# Screen List And UI Flow

## Shared Page Glossary

- `Role Dashboard`
  the role-aware landing page shown after login
- `My Work Dashboard`
  the personal work view for assigned tasks, due follow-ups, and action items
- `Client Directory`
  the client list and client detail area
- `Requisition Detail`
  the detailed requisition view with structured requirement data
- `Candidate Profiles`
  the candidate list and candidate detail area
- `Daily Updates Submission`
  the page where users submit execution updates
- `Daily Updates Review`
  the page where configured reviewers track submitted updates

## 1. Role Dashboard

- Admin view: company health, location comparison, approvals, SLA breaches
- Manager view: location health, portal availability, meetings due, follow-ups due
- HR view: assigned requisitions, priority work queue, portal slot today when applicable, interviews today, updates due

## 2. Requisition Detail

- Show direct client and optional end client
- Show structured JD summary
- Show must-have skills
- Show good-to-have skills
- Show allowed employment gap
- Show required documents like payslips and relieving letters
- Show important notes to remember
- Show whether client round is required

## 3. Delivery Work Queue

- Sort work by end date and urgency
- Highlight overdue and high-priority roles
- Show recommended next action
- Show SLA pressure

## 4. Candidate Screening

- Validate candidate against must-have skills
- Validate employment gap rules
- Validate documents provided
- Validate notice period and compensation fit
- Mark pass or fail before client round

## 5. Candidate Profiles

- Show sourcing portal
- Show uploaded required documents
- Show screening checks
- Show rejection side and reason if rejected

## 6. Pipeline Board

- Support optional client-review stage
- Show internal-side rejection reason
- Show client-side rejection reason

## 7. Notifications Center

- Priority role alerts
- Update submission reminders
- Follow-up alerts
- Overdue requisition alerts
- Portal slot reminders when applicable
