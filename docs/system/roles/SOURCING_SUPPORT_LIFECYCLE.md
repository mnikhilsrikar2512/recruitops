# Sourcing Support Lifecycle

## Purpose

The `sourcing_support` role supports delivery execution by finding prospects, preparing candidate drafts, and improving data completeness for recruiters.

## Typical Customer Title Mappings

- Assistant Recruiter
- Resourcer
- Sourcing Specialist
- Recruiting Coordinator
- Talent Sourcer

## Main Responsibilities

- search for candidates
- prepare candidate draft records
- upload resumes and supporting data
- enrich records before recruiter review
- support recruiter productivity

## Primary Records Owned Or Controlled

- candidate drafts
- resume uploads
- sourcing notes
- portal usage records
- candidate completeness tasks

## Daily Lifecycle

### Step 1. Review sourcing queue

- review roles assigned for sourcing support
- review urgent search requests
- review missing-data cleanup tasks

### Step 2. Search and collect candidate information

- search available portals or internal databases
- identify relevant candidates
- collect resumes and contact details

### Step 3. Prepare candidate drafts

- create candidate draft record
- upload resume
- fill contact and source details
- flag missing information where appropriate

### Step 4. Check duplicate and completeness basics

- check for obvious duplicates
- ensure required fields are present
- ensure documents are attached when available

### Step 5. Hand off to recruiter

- mark candidate ready for recruiter review
- attach sourcing notes
- flag concerns or missing information

## Weekly Lifecycle

- review sourced profiles created
- review incomplete candidate drafts
- review support load by requisition
- review portal usage volume

## Monthly Lifecycle

- review sourcing throughput
- review recruiter acceptance rate on sourced profiles
- review source-channel usefulness

## Key Screens And Views

- sourcing queue
- candidate draft flow
- resume upload flow
- duplicate-warning flow
- portal-account reference views

## Important Handoffs

- receives work from `delivery_lead` or `recruiter`
- hands prepared candidate drafts to `recruiter`
- may coordinate with `operations_admin` for portal or data issues

## Success Metrics

- candidate drafts created
- recruiter acceptance rate
- record completeness before handoff
- low duplicate-draft rate

## MVP Expectations

For MVP, this role should be able to:

- create candidate drafts
- upload resumes
- populate source and identity basics
- hand candidates to recruiter workflow
