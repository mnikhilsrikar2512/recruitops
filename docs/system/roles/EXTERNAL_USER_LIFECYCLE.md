# External User Lifecycle

## Purpose

The `external_user` role provides controlled access for non-employee participants such as clients, vendors, or external reviewers when a customer needs limited collaboration.

This role is not part of the MVP core unless external sharing becomes mandatory.

## Typical Customer Title Mappings

- Client User
- Vendor Recruiter
- External Reviewer
- Partner Contact

## Main Responsibilities

- view only shared records
- provide limited feedback or status updates
- collaborate on assigned workflow checkpoints

## Primary Records Owned Or Controlled

- shared requisitions
- shared candidate submissions
- feedback responses
- limited collaboration tasks

## Daily Lifecycle

### Step 1. Review shared items

- open only explicitly shared requisitions or candidates
- view allowed context and deadlines

### Step 2. Submit limited response

- provide feedback
- confirm status
- request clarification where permitted

### Step 3. Complete external action

- submit decision or comment
- return item to internal workflow owners

## Weekly Lifecycle

- review pending shared actions
- complete outstanding client or partner responses

## Monthly Lifecycle

- review collaboration usage if enabled by the customer

## Key Screens And Views

- shared review inbox
- limited candidate or requisition detail
- feedback submission form

## Important Handoffs

- receives shared workflow tasks from internal owners
- returns response to `client_manager`, `delivery_lead`, or `reviewer` workflow

## Success Metrics

- turnaround time on shared feedback
- low unresolved external actions
- secure limited visibility with no data leakage

## MVP Expectations

For MVP, this role can remain unimplemented unless a concrete customer workflow needs it.
